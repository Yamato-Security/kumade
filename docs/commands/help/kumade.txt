Version: 0.1.0

Windows DFIR Triage Collector — development prototype

Usage: kumade [OPTIONS]
       kumade <COMMAND>

Commands:
  check-support    Check platform support and acquisition prerequisites
  collect          Collect DFIR artifacts
  collect-test     Discover files and write a plan without copying evidence
  forensic-copy    Create a bit-for-bit image of a logical Windows partition
  help             Print this message or the help of the given subcommand(s)
  list-artifacts   List supported DFIR artifacts
  list-vss         List local Volume Shadow Copies
  live-info        Capture live Windows response data
  receive-sftp     Receive evidence through a temporary upload-only SFTP account
  resume-s3        Resume phased S3 uploads from a protected workspace without reading original sources
  scan-processes   Scan running Windows processes with YARA Forge or local YARA rules
  update-rules     Download or update a compressed YARA Forge rule package
  verify           Verify the integrity of a local Kumade collection
  verify-delivery  Verify an SFTP delivery locally and optionally reconstruct files
  verify-s3        Verify an S3 collection against its delivery hash and optionally restore it

Run `kumade <COMMAND> -h` for its options.
