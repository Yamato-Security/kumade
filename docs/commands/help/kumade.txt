Version: 0.1.0

Windows evidence collection by Yamato Security — development prototype

Usage: kumade [OPTIONS]
       kumade <COMMAND>

Commands:
  collect          Collect selected artifacts into a new, hash-verified run directory
  doctor           Inspect platform support and acquisition prerequisites
  forensic-copy    Image a logical partition to a raw file on a different external drive
  live-info        Capture live Windows response inventory without copying forensic artifacts
  list             List the embedded or explicitly selected acquisition catalog
  list-vss         List existing local Volume Shadow Copies without creating or deleting them
  update-rules     Download or update a compressed YARA Forge rule package
  plan             Discover files and write a plan without copying evidence
  receive          Receive evidence through a temporary upload-only SFTP account
  resume-s3        Resume phased S3 uploads from a protected workspace without reading original sources
  verify-delivery  Verify an SFTP delivery locally and optionally reconstruct files
  verify-s3        Verify an S3 collection against its delivery hash and optionally restore it
  scan-processes   Scan running Windows processes with YARA Forge or local YARA rules
  verify           Verify the seal and every stored payload; never reads original sources
  help             Print this message or the help of the given subcommand(s)

Run `kumade <COMMAND> -h` for its options.
