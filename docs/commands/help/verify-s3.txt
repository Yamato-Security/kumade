Version: 0.1.0

Verify an S3 collection against its delivery hash and optionally restore it

Usage: kumade verify-s3 [OPTIONS] --s3 <S3> --sha256 <SHA256> --receipt <RECEIPT>

Options:
  -h, --help  Print help

Delivery Verification:
      --s3 <S3>          Full s3:// URI of the delivery or phase manifest printed by the collector
      --sha256 <SHA256>  SHA-256 recorded independently from the collector

S3 Connection:
      --s3-region <S3_REGION>      AWS region (default: AWS_REGION, AWS_DEFAULT_REGION or us-east-1)
      --s3-endpoint <S3_ENDPOINT>  Explicit S3-compatible HTTPS endpoint (HTTP allowed on loopback for testing)

Output and Restore:
      --receipt <RECEIPT>                  New local receipt file
      --restore <RESTORE>                  Optional new local directory for restored evidence
      --max-decoded-gib <MAX_DECODED_GIB>  Maximum total decoded GiB [default: 1024]
